# 🍔🌭 Larry's Hot Dog Restaurant Website

This repository contains an interactive website for the fictional **Larry's Hot Dog Restaurant**. The project is built using **React**, **TypeScript**, and **CSS**, and was originally started on **Lovable** and later customized.

---

## 🌟 Features

- 📝 **Menu Page** – Browse all the hot dogs and dishes offered  
- 🏛️ **About Us** – Learn about the restaurant's history and story  
- 💬 **Reviews** – User comments and feedback  
- 📞 **Contact Information** – Phone, email, and address  
- 📨 **Feedback Form** – Submit your suggestions or reviews  

---

## 🛠️ Technologies Used

- ⚛️ **Frontend:** React + TypeScript + CSS  
- ⚙️ **CI/CD:** GitHub Actions (YAML-based workflows)  
- 🏗️ **Project Base:** Started from Lovable and customized
